<div class="document-card">
    <h2>Glossary</h2>
        <p> <strong>API</strong> — Application Programming Interface</p>
        <p> <strong>Custom Expense Splitting</strong> — dividing an expense among users using user-selected amounts or percentages.</p>
        <p> <strong>Git</strong> — Distributed version control system</p>
        <p> <strong>GitHub</strong> — Software development and repository-hosting platform.</p>
        <p> <strong> Household Group </strong> — A set of members belonging to a household that share expenses.</p>
        <p> <strong>MFCD</strong> — Major Functional Component Diagram; a high-level view of system components and their relationships.</p>
        <p> <strong>OCR</strong> — Optical Character Recognition; technology that extracts texts from images. </p>
        <p> <strong>PostgreSQL</strong> — Relational database management system</p>
        <p> <strong>React Native</strong> — Framework for developing application interfaces</p>
        <p> <strong>React Native for Web</strong> — Technology for using React Native components in web browsers</p>
        <p> <strong> Savings Goal </strong> — Optional target amount member(s) want to save for </p>
        <p> <strong>SEFire</strong> — Shared household Expense management application</p>
        <p> <strong>Supabase</strong> — Backend development platform</p>
        <p> <strong>Tesseract OCR</strong> — Optical character recognition engine</p>
        <p> <strong>Tessaract.js </strong> — JavaScript library used to run Tessaract OCR.
        <p> <strong>UI</strong> — User interface, which is the point of contact and interaction between a human and a device, program, or website.</p>
        <p> <strong>Variable Expense</strong> — An expense whose amount can change between billing periods.
        <p> <strong>Vercel</strong> — Web application hosting and deployment platform</p>
        <p> <strong>VS Code</strong> — Visual Studio Code, source-code editor</p>
